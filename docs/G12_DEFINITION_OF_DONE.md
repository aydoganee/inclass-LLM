# Definition of Done

**Team:** Group 12  
**Project:** InClass LLM Platform  
**Applies to:** Sprint 1 & Sprint 2

---

## Task Level — Done means:

- [ ] Code written and locally tested (no failing tests)
- [ ] All acceptance criteria for the user story are met
- [ ] Code pushed to its own feature branch (branch name: `US-<ID>`)
- [ ] Pull Request opened on GitHub
- [ ] At least one code review comment from a teammate
- [ ] PR merged to `main`
- [ ] ClickUp task status updated to "Done"

## Sprint Level — Done means:

- [ ] All committed Sprint Backlog items satisfy the Task Level DoD above
- [ ] All unit tests pass: `.venv/bin/python -m pytest tests/ -v`
- [ ] API signatures verified against instructor contract
- [ ] Supabase schema is consistent with implemented services
- [ ] Sprint Review conducted with stakeholders
- [ ] Sprint Retrospective conducted with action items recorded
- [ ] Burndown chart updated and saved
- [ ] All Scrum evidence files added to `docs/` and committed
- [ ] Scope Change Log updated with all status transitions
- [ ] ZIP submission package prepared and verified
- [ ] Git sprint tag pushed (`sprint-1` or `sprint-2`)
