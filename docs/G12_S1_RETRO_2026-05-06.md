## What Went Well

- **All stories completed:** We delivered 63 SP in Sprint 1 — every user story from US-A to US-M is implemented.
- **Branch-per-story discipline:** Using feature branches and PRs made it easy to track who did what and enabled code reviews.
- **LLM integration worked first try:** The OpenRouter integration for the tutoring flow worked with the first prompt; the objective detection JSON marker approach is clean and reliable.
- **Supabase schema was stable:** The initial schema design required no migrations during the sprint.

---

## What Could Be Improved

- **No unit tests written in Sprint 1:** Everything was tested manually via Postman. We relied on API contract compliance but had no automated regression protection.
- **Daily Scrum wasn't daily:** We skipped Day 4 and Day 5. We should commit to every working day in Sprint 2.
- **Evidence collection left to the end:** Daily scrum notes and burndown chart were filled in at the end of sprint. This is risky.
- **Python 3.9 compatibility issue surfaced late:** The `from __future__ import annotations` fix had to be added after a teammate couldn't run the code. Should have been caught in a shared dev environment check.
