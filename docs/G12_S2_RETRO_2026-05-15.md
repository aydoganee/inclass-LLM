## What Went Well

- **Test coverage improved significantly:** Adding conftest.py unblocked all 39 unit tests that were previously failing due to env-var import errors. Clean test run is now part of the workflow.
- **Branch-per-task discipline:** Each task (US-T3, US-T6, US-T7) had its own branch with a clear commit history and PR, making it easy to trace who did what.
- **Seed script is idempotent:** seed_demo_data.py can be safely re-run without duplicating data, which saved time during demo preparation.
- **Evidence collection was structured:** prepare_submission.py with its checklist made it clear which evidence items were missing at any point in time.
- **Team communication:** Task assignments in ClickUp were clear; no duplication of effort.

---

## What Could Be Improved

- **Late screenshot collection:** Post-daily ClickUp board screenshots were not taken consistently. We should take them immediately after each daily scrum next sprint.
- **Credentials sharing:** The .env file with Supabase credentials was not shared with all team members at the start of the sprint, which blocked testing for a day.
- **Burndown chart:** We did not update the burndown chart daily; it was filled in retrospectively. Next sprint, one person should own this and update it each day.
- **Sprint 1 evidence gaps:** Some Sprint 1 evidence files were missing and had to be reconstructed near the deadline. Evidence should be collected continuously, not at the end.
